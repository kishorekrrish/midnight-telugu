# Prompt: YouTube Metadata — Midnight Telugu

## Title Rules

- Include the story title in Telugu
- Add "| Midnight Telugu" branding
- Add "| Telugu Short Story" or "| Telugu Mystery"
- Keep under 70 characters total
- No ALL CAPS
- No fake clickbait ("You won't believe...", "SHOCKING")
- No promises the video doesn't deliver

### Good Title Examples
- `అర్థరాత్రి తలుపు | Midnight Telugu | Telugu Mystery Short`
- `పాత బావి రహస్యం | Midnight Telugu | Telugu Story`
- `నా భార్య ఎవరు? | Midnight Telugu | Psychological Twist`

## Description Rules

- First 2–3 lines visible before "Show more" — make them engaging
- Include the hook line in Telugu
- Channel description block (copy-paste standard)
- Hashtags at the bottom
- No spam text, no keyword stuffing, no misleading links

### Description Template
```
[Hook line in Telugu]

[1-2 line story teaser — no spoilers]

Midnight Telugu — మిస్టరీ, హారర్, సస్పెన్స్ Telugu Short Stories.
రోజూ కొత్త కథలు. Subscribe చేయండి.

[3-4 relevant hashtags]
```

## Hashtag Rules

- 3–5 hashtags maximum
- Telugu-relevant: #MidnightTelugu #TeluguShorts #TeluguMystery #TeluguStories #TeluguSuspense
- No irrelevant trending tags
- No tags that misrepresent the content

## Chapter Markers (Future)

For longer content, add chapter markers. Not applicable to 60-second Shorts.
