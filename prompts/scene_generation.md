# Prompt: Scene Generation — Midnight Telugu

## Task

Convert a Telugu narration script into 6–10 production-ready scenes for video composition.

## Scene Requirements

Each scene must include:

| Field | Description |
|-------|-------------|
| scene_number | Sequential, starting at 1 |
| timestamp_range | e.g. "00:00-00:07" |
| narration_line | The Telugu text spoken during this scene |
| visual_description | What the viewer sees |
| characters_present | List of characters visible |
| location | Specific location (e.g., "పాత ఇల్లు లోపల") |
| mood | e.g., "tense", "melancholy", "eerie" |
| camera_angle | close-up / medium shot / wide shot / low angle etc. |
| motion_direction | slow zoom in / pan left / static etc. |
| image_prompt | Detailed English prompt for image AI |
| negative_prompt | What to exclude from the image |

## Image Prompt Style

Write cinematic, photorealistic prompts:
- "Cinematic South Indian scene, [description], [mood] lighting, 9:16 vertical frame..."
- Use mood words: "dramatic side lighting", "warm golden hour", "cold blue midnight"
- Specify Indian/Telugu cultural details: clothing, architecture, environment
- Do NOT reference copyrighted styles, celebrity faces, or brand names
- Include "no text, no watermark, no anime" in negative prompt

## Scene Flow Guidelines

- Scene 1: Establish mood and hook visually
- Scenes 2-3: Setup and character/location
- Scenes 4-6: Rising tension
- Scene 7-8: Approach to reveal
- Scene 9-10 (if present): Reveal and emotional landing

## Consistency

- Characters should look the same across scenes (describe appearance once, reference it)
- Location lighting should be consistent within scenes set in the same place
- Mood shift should be gradual, not jarring between adjacent scenes
