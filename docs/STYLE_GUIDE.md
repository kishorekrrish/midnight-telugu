# Telugu Style Guide — Midnight Telugu

## Target Voice

Natural, conversational Telugu storytelling. Like a friend telling you a suspense story at night — not a textbook, not a news reader, not a robot.

## Language Rules

### DO
- Use neutral Andhra + Telangana mix
- Use everyday spoken words: "అన్నాడు" not "చెప్పాడు" when possible
- Use em-dashes for dramatic pauses: "ఆ తలుపు తెరిచాడు — లోపల ఎవరూ లేరు."
- Use short sentences for tension
- Use rhetorical questions to engage: "మీరు ఇది నమ్ముతారా?"
- Start with a question or incomplete thought to hook

### DON'T
- Never use "ఒకానొక రోజు" (classic AI opener)
- Never use "ఆశ్చర్యకరంగా" (surprisingly)
- Never use textbook formal Telugu ("వారు నిష్క్రమించారు" → use "వాళ్ళు వెళ్ళిపోయారు")
- Never moralize ("నీతి: మంచి చేయాలి")
- No heavy Hyderabadi slang (excludes Andhra audience)
- No Sanskrit-heavy words unless necessary
- No English words unless the character would realistically use them

## Banned Patterns

| Banned | Use Instead |
|--------|-------------|
| "ఒకానొక రోజు..." | Specific time: "ఆ సోమవారం రాత్రి..." |
| "అది చాలా ఆశ్చర్యకరంగా ఉంది" | "నోరు తెరుచుకుపోయింది" |
| "నీతి ఏమిటంటే..." | Let the story speak |
| "Share చేయండి, Subscribe చేయండి" mid-story | Only at the very end |
| Celebrity/film character names | Fictional original characters |

## Sentence Rhythm

Good Telugu Shorts narration has rhythm:
- Short punch sentence.
- Longer build-up sentence with detail.
- Pause — em-dash or paragraph break.
- Short reveal.

## Emotion Level

Emotional but not melodramatic. The story creates feeling — the narrator doesn't tell the audience how to feel.
